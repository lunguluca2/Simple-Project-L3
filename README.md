# Simple Webpage

A small static webpage built with HTML5 and CSS3. It includes a header with section navigation, an image gallery, and a footer.

## Features

- Navigation links to the Home, About, and Contact sections
- Home, About, Gallery, and Contact content sections
- Gallery with three placeholder images arranged in a three-column CSS Grid
- Responsive gallery that switches to one column on screens narrower than 600px
- CSS hover effects for navigation links

## Project Files

- `index.html` - Page structure and content
- `styles.css` - Layout, colors, gallery grid, and responsive styles

## Run Locally

Open `index.html` in any modern web browser. No build tools or dependencies are required.

The gallery placeholder images are loaded from `placehold.co`, so an internet connection is needed to display them.

## Technologies

- HTML5
- CSS3
